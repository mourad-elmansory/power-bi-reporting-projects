# Power BI Reporting Projects

Power BI dashboards and KPI reporting, mainly for poultry production analytics.

## What this is

A place for my reporting work as a data analyst. The dashboards turn daily production data into clear views for managers.

## KPIs covered

- Feed conversion
- Egg production
- Mortality and flock health
- Feed consumption
- Diesel and energy reconciliation

## Tools

- Power BI
- DAX
- Power Query
- Advanced Excel (pivot tables)
